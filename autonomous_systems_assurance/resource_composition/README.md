# Resource composition

This folder develops the paper and resource package from maintained research. It is not a dump of the working repository.

- [Whitepaper outline](whitepaper_outline.md): argument, evidence and figure plan.
- [Whitepaper review draft](whitepaper.md): worked road-to-air vision case, AMLAS training failure modes, assurance architecture and source-linked claims.
- [Figure plan](figures.md): visual assertions that require the same claim review as prose.
- [CrossPoint PDF review toolkit](crosspoint_review/README.md): provenance-preserving EPUB review packages for Xteink X4 Pro; generated packages remain under ignored `out/` paths.
- [Public export plan](../publication/README.md): curated inventory and release requirements.

Use [review_prototype/render.sh](review_prototype/render.sh) to build the current linked HTML and paginated PDF from the Markdown manuscript. Generated PDF stays under ignored `out/` until selected for release.

The paper, script, figure descriptions and future launch text are compiler inputs. Their wording needs review even when they reference an accepted underlying claim.
