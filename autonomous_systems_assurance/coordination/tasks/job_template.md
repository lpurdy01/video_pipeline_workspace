## Deliverables

- Research: contribution source/claim registries matching current schema, dated search notes, source inspection scope and unresolved questions.
- Composition/production: scoped prose or visual changes, exact claim uses and shared-example change proposals.
- All jobs: completed [handoff](../handoffs/template.md), changed-file manifest with hashes and verification results.

## Acceptance checks

- IDs and output paths remain inside the assignment.
- Quotations, dates, source editions, regions and claim scope are inspectable.
- Search failure, source assertion, inference and established approval are distinguished.
- Contrary findings and uncertainty survive the handoff.
- No claim is declared accepted based solely on agent agreement.
- Referenced snapshots exist locally and match hashes; unavailable materials are recorded as unavailable.
- The selected compiler version can parse the completed contribution, or the exact incompatibility is reported.

## Coordinator disposition

Record handoff version/hash, review assignment, integration order, ID remapping, accepted changes, returned changes and the next baseline. Integration status does not itself grant publication approval.
