# Intake findings — 2026-09-15

This intake supplies primary authority documents and a live lookup snapshot. It does not make Tesla the project's central case. The reusable lesson is that a public operation, an exemption with conditions, a TSO, an equipment authorization, an aircraft installation approval, and a certification conclusion are separate evidence objects.

- Zipline Exemption 19111B contains the unusually clear distinction that the operational exemption did not itself authorize the DAA system. Its 2024 amendment adds a safety-case and airspace-analysis obligation for DAA expansion.
- TSO-C211a is now a direct primary source for the equipment/installation distinction. It gives the project a concrete standard without implying that any named article is authorized or installed.
- Amazon 19031B is a useful counterexample: the document notes that requested relief to remove visual observers with onboard DAA was still under review. Do not imply that an operator's public DAA program is the same as granted relief.
- The live Texas lookup now exposes a Tesla Robotaxi, LLC record with Cybercab rows. It is a dated road-authorization fact, not a safety result. It should be used only if a fresh, narrow road-regulation example helps the opening.
