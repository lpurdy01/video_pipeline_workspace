# Graphify Corpus

This folder is the curated input area for exploratory Graphify runs.

Do not treat this folder as the source of truth. Raw source files remain in `refrence_literature/`, and verified synthesis lives in `project_wiki/`.

Use this folder when a Graphify run needs a clean subset of the repository, for example:

- selected source notes
- selected extracted source documents
- whitepaper structure files
- project wiki pages

Generated Graphify output should go to `graphify-out/`.
