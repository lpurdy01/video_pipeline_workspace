# Orbital Tech Tree Refinement Prompts

These prompts use the 02 circular 3D orbital skill-tree concept as a reference. The goal is to refine Manim layout, camera staging, fog concealment, and node positioning. The video should not show the complete map until the ending.

## Shared Context

Use the provided reference image as the visual seed: a dark 2.5D orbital technology tree divided into colored wedges, with a flat researched disk, raised convergence bridges, and an outer frontier shell/fog. Refine the structure for a Manim animation, not a poster.

Important narrative constraint: the full tree must not be readable until the end of the video. Earlier views should show only partial regions, cropped camera angles, fog-obscured branches, or local closeups. The viewer should gradually learn the geography.

Style constraints:

- Dark mathematical atlas, crisp neon geometry, 3Blue1Brown-style clarity.
- Mostly flat 2.5D disk, not chaotic full 3D.
- Text labels should be sparse and readable only when the camera is settled.
- Fog should hide unrevealed regions but not make visible labels muddy.
- Use colored wedge identity consistently: cyan signal/media, gold dynamics/control, violet learned spaces, green/blue software/verification, pale shell frontier.
- No fantasy UI ornament, no cartoon characters, no corporate dashboard, no generic sci-fi city.

## Prompt 1: Opening Fog Glimpse

Design a concept frame for the opening of the video. The viewer is close to the orbital tree but cannot see the full map. Only fragments of glowing arcs and a few partial nodes are visible through camera-locked fog: Fourier, Laplace, DCT, and one distant violet learned-representation glow. Most labels are hidden or absent. The frontier shell feels like mist at the edge of vision, not a readable structure. The camera angle should imply a larger disk beyond the frame. Make this useful for a Manim shot where fog masks and cropping conceal the map until later.

## Prompt 2: Classical Foundation Region

Design a concept frame for the early classical-transform section. The camera is settled over only two adjacent regions of the disk: classical signal/media transforms and dynamics/control. Fourier branches toward frequency-domain view, signal processing, wireless communication, compressed audio, and spectral imaging. DCT branches toward JPEG and video codecs. Laplace branches toward transfer functions, stability/control, feedback controllers, brushless motors, and flight/robotics stability. Everything outside these regions is dark, cropped, or fogged. Do not show the full tech tree. The point is to position these classical branches clearly for staged Manim reveals.

## Prompt 3: Modern Region Without Full Reveal

Design a concept frame for the middle of the video when learned representations and language/code become visible. The view should show neural networks, embeddings, transformers, LLMs, code agents, research assistants, and maybe V&V/evidence systems. The LLM-to-code branch should feel like a bridge from learned representation spaces into software/verification. Keep the classical regions only as dim offscreen hints or far-edge glows; do not reveal the full disk. Labels should be sparse and readable. Show how local inset scenes could cut away from this region without needing a literal camera dive.

## Prompt 4: Convergence Bridge Partial Pullback

Design a concept frame for sections 8-10: a partial pullback that shows multiple regions belong to one map without revealing the whole thing. Raise a glowing bridge from state-space models to neural SSMs to LLMs. A second bridge hints at LLMs to code agents to V&V/evidence workflows. The frontier shell should be felt as pressure outside the known disk, but frontier labels remain hidden. The camera angle is a restrained 2.5D tilt with screen-facing labels. This should guide Manim bridge height, bridge routing, and crop/fog boundaries.

## Prompt 5: Final Full Reveal

Design the ending reveal. For the first time, show the full researched disk inside a dim frontier shell. The classical, dynamics, learned, and language/code/verification wedges are all visible, with only the most important labels readable. Raised convergence bridges pulse above the disk. The frontier shell is visible but partly foggy, with speculative nodes faint and not overconfident. This should feel like the final synthesis: the technology tree has changed, and some branches are still hidden in the fog.
