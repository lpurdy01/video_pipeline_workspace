== ABSTRACT ==

VeriGuard provides formal safety guarantees for LLM-based agents through a dual-stage
architecture:

STAGE 1 (Offline):
  - Clarify user intent
  - Synthesize behavioral policies
  - Conduct testing and formal verification
  - Iteratively refine policies until correctness is established

STAGE 2 (Online/Runtime):
  - Runtime monitoring: validate each proposed action against pre-verified policies
  - Reject actions that violate verified policy specifications before execution

Targets autonomous AI agents in sensitive domains (healthcare mentioned in general context).

== WHAT THIS PAPER ACTUALLY SHOWS ==

This is NOT about using LLMs to verify code for safety properties.
This IS about using formal verification to ensure LLM-generated code/actions comply with
pre-specified safety policies.

The paper provides a framework for making LLM AGENTS safer — it wraps LLM code generation
with formal verification infrastructure to catch policy violations.
