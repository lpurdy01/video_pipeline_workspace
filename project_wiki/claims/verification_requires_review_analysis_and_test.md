# Verification Requires Review, Analysis, and Test

## Claim

Safety-critical verification is a structured evidence process that includes reviews, analyses, and tests, not testing alone.

## Status

Candidate, supported by Rierson. Needs at least one primary or agency source before final whitepaper use.

## Supporting Sources

- Rierson: DO-178C verification includes reviews, analyses, and tests, and verification objectives make up a major part of software development assurance. Evidence location: Rierson Markdown line 4295.
- Rierson: software verification planning explains how reviews, analyses, tests, checklists, traceability, pass/fail criteria, and verification results are handled. Evidence location: Rierson Markdown line 6042.
- [FAA AC 20-115D](../sources/faa_ac_20_115d.md): public FAA guidance frames ED-12C/DO-178C use as satisfying objectives and producing associated life cycle data. Evidence location: `faa_ac_20_115d.txt` line 143.
- [NPR 7150.2D](../sources/npr_7150_2d.md): NASA requires project access to review verification activities, audit development processes, and receive traceability/change/nonconformance information. Evidence location: `npr_7150_2d.txt` line 840.

## Challenges or Uncertainty

- FAA and NASA public sources now support this as a central claim, though direct DO-178C text remains unavailable because of licensing.
